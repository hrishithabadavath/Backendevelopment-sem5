# 🧪 Experiment 12B — Node.js, Sessions and Cookies

## 📌 Aim

To understand backend development using Node.js and explore concepts related to server-side programming, sessions, cookies, and web application functionality.

## 📖 Description

This experiment contains a Node.js project with server-side JavaScript files and supporting folders. It provides practical experience with backend application structure and server execution.

The project includes files for server functionality, storage-related operations, and a To-Do application.

## 🛠️ Technologies Used

- Node.js
- JavaScript
- HTML and CSS
- npm (Node Package Manager)
- Express.js, if configured in the project

## 📂 Project Structure

```text
Experiment-12b/
├── Source/
├── public/
├── node_modules/
├── .gitignore
├── package.json
├── package-lock.json
├── server.js
├── storage-server.js
├── todo.js
└── README.md
```

## 📄 File and Folder Description

- **`server.js`** — Contains the main server-side JavaScript code.
- **`storage-server.js`** — Contains code related to the storage server.
- **`todo.js`** — Contains JavaScript functionality for the To-Do application.
- **`public/`** — Stores public-facing assets used by the application.
- **`Source/`** — Contains additional source files for the experiment.
- **`package.json`** — Defines project metadata, dependencies, and available scripts.
- **`package-lock.json`** — Records the dependency versions used by npm.
- **`.gitignore`** — Specifies files and folders Git should ignore.
- **`node_modules/`** — Contains installed project dependencies.

## ▶️ How to Run

1. Open the `Experiment-12b` folder in VS Code.
2. Open the integrated terminal.
3. Install dependencies if needed:

   ```bash
   npm install
   ```

4. Check `package.json` to identify the available scripts and the correct entry point.
5. Start the application using the appropriate command. For example, if `server.js` is the intended entry point:

   ```bash
   node server.js
   ```

6. Open the local URL shown in the terminal.

## 🎯 Learning Outcomes

- Understand the structure of a Node.js application.
- Learn how server-side JavaScript is organized.
- Gain experience running a backend server.
- Explore the relationship between server-side code and public web assets.
- Understand session and cookie concepts if implemented in the experiment.
