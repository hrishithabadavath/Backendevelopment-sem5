## ▶️ How to Run the Experiments

### HTML, CSS and JavaScript

1. Open the experiment folder in VS Code.
2. Open `index.html` in a browser.
3. Alternatively, use the Live Server extension.

### Node.js and Express.js

1. Open the relevant experiment folder in the terminal.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the application using the entry point specified in the experiment's README:

   ```bash
   node app.js
   ```

4. Open the local URL displayed in the terminal.

*Note: Some projects may require environment variables or a running MongoDB database.*
