# Experiment 07 & 08: ES6, DOM Manipulation, and Event Handling

## 1. Objective

To understand and apply ES6 (ECMAScript 2015) features, learn DOM (Document Object Model) manipulation, and implement event handling to build an interactive web application.

## 2. Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Visual Studio Code
- Web browser

## 3. Description

This experiment combines modern JavaScript features with DOM manipulation and event handling to create an interactive To-Do List application.

Users can add tasks, mark tasks as completed, and delete tasks dynamically without reloading the page.

## 4. Concepts Covered

### ES6 Features
- `let` and `const`
- Arrow functions
- Template literals
- Destructuring
- Spread operator
- Classes and constructors

### DOM Manipulation
- Selecting elements using `getElementById()`
- Creating elements using `createElement()`
- Updating content using `textContent`
- Adding elements using `appendChild()`
- Managing CSS classes using `classList`
- Using `dataset` to store task IDs

### Event Handling
- `addEventListener()`
- Form submission events
- Keyboard interaction through the form
- Event delegation
- `preventDefault()`

## 6. How to Run

1. Open the `exp 7 and 8` folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click the file and select **Open with Live Server** if the extension is installed.
4. Alternatively, open `index.html` directly in a modern web browser.

No additional packages or database are required.

## 7. Features

- Add a new task.
- Add tasks by pressing Enter.
- Mark a task as completed by clicking its name.
- Delete tasks.
- Display the total number of tasks and remaining incomplete tasks.
- Update the page dynamically using JavaScript.

## 8. Expected Output

A To-Do List web page with a text input, an Add Task button, a task list, and a task counter. Tasks can be added, completed, and deleted interactively.

## 9. Conclusion

This experiment demonstrates how ES6 features, DOM manipulation, and event handling work together to create an interactive web application. It provides practical experience with modern JavaScript and the fundamentals of front-end web development.
